# Missing assets

Status: Phase 2 of the master prompt. The sandbox (and the offline
budget) allows only `github.com`, `registry.npmjs.org` and `pypi.org` —
CDN model packs (Kenney, Quaternius, Poly Haven, ambientCG) cannot be
downloaded here, and nothing may be fetched at runtime. Everything the
slice needs was therefore **generated by our own build script** under
CC0, and the gaps below are what would still be commissioned or pulled
from a vetted pack when a network is available.

## What the pipeline generates (no external files)

`Hugo-Project/tools/make-models.mjs` builds 31 GLBs in headless
Chromium with three.js and exports them meshopt-compressed, plus a baked
128px icon per model (used for inventory/market item art):

- **vehicle** — `buggy` with named nodes `chassis`, `hood`, `seat`,
  `steering`, `wheel_fl/fr/rl/rr` (axles at the physics positions,
  front = +z); wheels spin and steer from the rig at runtime.
- **buildings/props** — fence, cot, shed, well, threshing floor,
  market stall.
- **animals** — cow, goat, chicken (swap in for the box placeholders).
- **crops** — `crop_{ragi,paddy,chilli,vegetable,cotton}` each with
  `stage0…stage3` nodes; the plot sync clamps the 5-stage crops.
- **tools** — hoe, sickle, rod, hammer, watering can, seed pot.
- **items** — paddy, rice, ragi, chilli, cotton, fish, milk, egg,
  vegetable, seeds (baked icons for the inventory + market).

Licences: all CC0-1.0 project artwork, recorded per file in
`Hugo-Project/static/assets/LICENSES.json`; `tools/check-assets.mjs`
(CI, in `run-all`) fails if a model, node name, triangle budget,
meshopt flag or licence sha is wrong.

## Explicitly rejected sources

- **Mixamo** — licence forbids redistribution; needs owner approval.
- **Any CC-NC / CC-ND / GPL / AGPL / "free for personal use" pack** —
  fails the project licence rule even when downloadable.
- **Runtime CDN fetches** — forbidden by the offline budget; assets
  must be vendored into `static/` and listed in LICENSES.json.

When a pack is added later: run `tools/make-models.mjs`-style
registration (file + sha256 + licence in `LICENSES.json`), keep
`tools/check-assets.mjs` green, and re-run the e2e + audit shots.
