# Offline acre database

1,193 `.bin` files, named `tileX_tileY`. A tile covers 256 × 256 virtual acres on the grid defined in `data/atlas.json` at the site root. `js/grid.js` contains the WGS84 projection, metre conversion and reader. The filenames are stable across all quality settings.

The ACP3 container in each `.bin` is a **lossless** transport. `js/acre-codec.js` is its reference decoder; `js/acre-probabilities.js` contains the shared cumulative counts, not any resident or route data. The vendored MIT-licensed `fzstd.mjs` reads the auxiliary Zstandard frame. Import `decodeAcre`, pass a `Uint8Array` and read the returned `ArrayBuffer`. `tiles.sha256.json` lists the SHA-256 of every original decoded TSA1 stream, before reconstruction of absolute heights. A check of the whole edition reconstructs 520,169,935 bytes; the 1,193 distributed tile containers total 39,118,095 bytes.

**Reader layout.** Four-byte magic `ACP3`, the original eight-byte TSA1 header, then five little-endian uint32 lengths: decoded auxiliary size, compressed auxiliary size, height-exception bytes, height stream bytes and slope stream bytes. After byte 32 come the Zstandard frame, signed int16 exception heights, then three byte-renormalized range-ANS streams (height, slope, tree cover; base 2¹⁴, initial state 2²³). Each stream starts with its 32-bit little-endian decoder state. The auxiliary frame is district IDs, water/mining class overrides, XOR corrections to the inferred eligibility bits, exact reported river widths and the original vector JSON bytes. Ordinary classes are inferred from the measured slope and cover and the stored overrides. Block occupancy predicts no-data; local height gradients and previous decoded samples select frequency rows. Predictors affect compression only, not the values, grid or walkable extent.

TSA1 offsets (bytes, multi-byte numbers little endian): magic at 0; signed tile X/Y at 4/6; 128 × 128 signed 16-bit row-delta elevations at 8 (wrap the cumulative sum to int16; −32768 is no-data); 256² byte arrays for slope, biome, district and tree cover at 32776, 98312, 163848 and 229384. At 294920 are 256² uint16 reported river widths in metres (zero = unknown or inapplicable); at 425992 is a packed buildability mask, and at 434184 the UTF-8 JSON vector paths. Use the accessors rather than guessing sentinel or land-use semantics. Inputs, licences and the limits of modelled water are in `credits.md` and `SOURCES.json`.
