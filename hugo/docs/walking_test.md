# Walking test · physical acceptance card

**Candidate, not approval:** 6.0.0-walk.1 (60001), same package and signer as 5.2.0-field.1. One offline APK, Android 8.0+. No need to uninstall, clear data or disable Play Protect. If Android requests it, allow your file manager to install this particular APK, then revoke that permission. No login or location permission. Prefer a current Android System WebView. Do not install the historical installer to run the test.

1. **Reproduce the original view.** Select Woman or Man, then **Walk in Bapatla**. The location chip should say Bapatla. Tap it for the coordinates: **15.991240 N, 80.260022 E**, acre **5901-6043**, source elevation **12 m**. Simulated weather can vary by session; the repeatable lab case was drizzle at 12:30 IST. In third person, move a little and drag the look side up to its limit, then down again. Both feet and the head should remain visible on this plain. Rotate to landscape and repeat. The scene should extend beneath the system bars and the buttons should avoid the cutout and gesture region. If a black strip appears, send a screenshot of the *whole* screen, including the system bars.
2. **Try the controls with real thumbs.** Left half moves, right half turns; two look-side fingers pinch camera range. Hold Sprint, push the movement stick to its rim, or double-tap Sprint to lock/unlock. Tap Jump vs holding it. Try moving, looking and pressing an action together. Open **☰ → Controls & camera** to mirror the layout, change sensitivity, invert Y, toggle recentering, optional vibration or Battery saver. Release everything: the character must stop. Lock/unlock the phone during a walk, then resume; it should not keep walking on its own.
3. **Check a real record and Photo.** Use the launcher's demo_user1 link or a resident search. Tap the username: the roof, walls, door and traveller should stay drawn behind the resident sheet. Try **Walk here**, then the menu's **Stand at the fence opening**. Walk in and out. Open **Photo mode**; try height, hour, weather, moving/pinching, then **Save picture**. Choose a file yourself; confirm the PNG opens, and that exiting Photo returns to the same position and normal weather. Back should close an open sheet/Photo first. A share action should show Android's chooser, not send anything automatically. Profile links open a separate app by choice; the atlas itself can be used offline.
4. **Record the device result while moving.** Use **☰ → Measure this walk → Start measurement**. Continue walking until the run finishes. Bapatla uses about 12 s; the timber acre and canopy walk use 60 s. Do one moving run in each orientation. Repeat after at least 10 minutes of ordinary walking to expose heat-related slowdown; note visible judder, temperature warning, sound and haptics (if enabled and supported). Compare Auto and Battery saver separately. Note any wall/terrain/camera penetration or loss of avatar. Do not benchmark a paused menu, or treat the saver’s 30 FPS *cap* as a measured rate.
5. Return to the field launcher with Back. **Share readings** opens a chooser; nothing is uploaded automatically. Send the saved JSON with phone model, Android / WebView version, orientation, tier, FPS, p95, worst frame, distance walked, warm/cold and whether symptoms reappeared. Do not approve the ≥30 FPS or physical comfort target from a desktop emulator.
