## Re-run the phone-feedback checks from the checkout

The new tests mount files from the supplied signed archive. They exercise Chromium’s touch dispatcher and WebGL (software rendering), **not** a connected phone. Use the same Node/Playwright environment as `browser/` and an installed Chromium (`/usr/bin/chromium` by default). Run GPU tests sequentially.

```sh
node browser/nature-map-touch.cjs SIGNED.apk /tmp/map-point.json
node browser/nature-rock.cjs SIGNED.apk /tmp/granite-check
node browser/nature-reservoir.cjs SIGNED.apk /tmp/shore-check
node browser/living-profile.cjs SIGNED.apk /tmp/moving-profiles
```

For the direct boulder test, a draw observer reads the real instanced rock geometry, not the collision helper. A camera ray must hit it *before* movement. While holding the production sprint/stick, measure the body centre against the projected triangles on each observed draw. Sliding around a boulder is allowed; entering its silhouette is not. The reservoir test walks in and out without a teleport. `nature_contacts.mjs` separately compares the production motor/capsule to sectioned triangles on ten transformed assets. These are bounded checks, not a guarantee for every placement.
