# From the map to a walk

The ordinary address opens a pannable SVG map. No Three.js renderer, model or terrain chunk is required just to see the two states. Select **Explore in 3D**, a green place marker, or a scenic card. A supported browser can enter fullscreen from that gesture; if it declines, the walk uses the viewport instead. The arrow returns to the map. Explore resumes the same player and camera without a page reload. Use the labelled place card on a small screen if overlapping markers would be inconvenient.

Search handles, @names or Instagram profile URLs. Only published community records are searched normally; a missing name never creates a house. A valid username routes through its frozen terrain and collision-aware entrance, not a guessed coordinate. The local map still works when WebGL is missing. `?dev=1` is a separate visual test mode and is not part of the public count.
