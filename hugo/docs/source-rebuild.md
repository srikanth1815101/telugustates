# Rebuilding this particular edition

**Do not rebuild geography to add a house.** The published grid is a permanent address system. The ordinary house command needs only Python 3.11+; its YAML reader is vendored. A full data rebuild is a separate maintainer task.

Tested on Debian 13, Python 3.13, GDAL CLI 3.10.3, 7-Zip, osmium-tool, and the Python libraries listed in `requirements-data.txt`. Install the system programs first (`sudo apt install gdal-bin osmium-tool 7zip` on Debian 13), then `python -m pip install -r requirements-data.txt`. Use a virtual environment on a system-managed Python. Allow about **12 GB free disk space and 2 GB RAM**; on other systems, allow extra. No Earthdata or cloud account is needed. Run from the repository root:

```sh
python scripts/build_all.py
python scripts/prepare_site.py --check
pytest
```

The reusable source observations in `data/frozen/basis/` are deliberate. Daily regional OSM extracts and dated LGD directory download URLs can expire. We preserve just the licensed, clipped observations for this edition rather than depend forever on a daily URL or bundle an entire multi-state extract. `admin.geojsonl.gz` contains the two state and 61 district polygons with source identifiers. `osm.wkb.gz` is gzip of `TSV1` followed by records: uint8 kind (4 river/5 mine), little-endian uint16 source width, uint32 geometry length, that many bytes of little-endian OGC WKB in ESRI:102028. `lgd.csv` is the independent official directory subset. The three digests are checked before use. These are observations, not generated shapes. `districts.geojson.gz` and `states.geojson.gz` are the finished display/analysis outlines. No regional PBF dependency at runtime.

Default rebuild: read verified regional observations; download or reuse the exact 43 Copernicus GLO-30 COGs, 9 WorldCover COGs and the HydroLAKES archive. Rebuild boundary joins, project native rasters, rebuild all tiles, render six debug maps, compute safe district arrival cells and bake the 61 village road/plot masks. A district’s full reachable component is independent of its current household count. It does **not** reuse finished terrain tiles as a shortcut. Source TIFFs intersect the states, not the whole Indian subcontinent. The large global HydroLAKES archive is temporary; only intersecting polygons enter the build. Source footprints can extend beyond the region; the final tiles, vectors and displays are masked to the states.

To repeat the *original* intake too, use `python scripts/build_all.py --from-sources`. This downloads the pinned daily PBF and LGD archive, the two geoBoundaries files and the alternate district file for comparison, the HydroRIVERS archive for the licence audit, and provider documentation. It resolves actual member ways and nodes, selects the four mine tags, river lines and mapped river polygons, and reconstitutes the regional observations. Expired dated URLs require the original verified raw cache or the default regional-basis rebuild; **do not rename a newer snapshot to the old filename**. `download_data.py`/`intake.py` use atomic file replacement and record actual download times, byte lengths and SHA-256. Metadata webpages can change; source data bytes are pinned. The original source receipt is committed as `data/frozen/SOURCES.json`; `data/raw/SOURCES.json` is the local download log.

`build_all.py` builds into a temporary staging directory with access to the raw cache. It compares the rebuilt grid/manifest identity to `data/residents.lock.json` **before replacing** the published atlas. If a library upgrade changes numerical results, the command stops; do not erase the lock. Keep the existing edition or design a new, explicitly versioned atlas. Use the tested package versions in `docs/tested-environment.txt` for a byte-identical rebuild. Once satisfied, review `git diff`, run tests, and commit `data/frozen`, `config` and `debug` together. The raw cache may then be deleted; keep a backup if you need an exact upstream audit.

## Integrated edition (70001)

From the delivered workspace use `python Living-World/restore.py --source NEW_DIRECTORY`. This restores the previous verified Git base first and fast-forwards to the pinned integrated branch. Nothing is installed or published. Within the clean checkout run `python -S scripts/prepare_site.py --write-back`, `python -S scripts/prepare_living.py`, and both corresponding `--check` commands. `python -S scripts/check_plots.py` and `python -S scripts/update_economy.py --check` audit existing state, never debit it. To produce the exact release website with Hugo 0.131.0 extended and libdeflate 1.23: `hugo -s site --minify -d /absolute/new/public`; then `python scripts/pack_transport.py --public /absolute/new/public`. Use an empty publication directory. Cached compressed tiles are optional. Hugo alone is valid for development but is **not** the pinned transport tree. All bytes are local.

Native: JDK 11, Android platform 35 / Build Tools 35.0.0 and a signing key. Invoke `python packaging/android/build_apk.py --public /absolute/new/public --keystore YOUR_KEY --out NEW.apk`. Set `ANDROID_HOME`, `JAVA_HOME` and `ATLAS_SIGN_PASS` in the process environment. Same signer's key is needed for an in-place update. A separately signed personal rebuild is not interchangeable with the delivered signed APK. No signing secrets are shipped. The prior signed installer is reconstructible using `python Living-World/restore.py --previous NEW_60002.apk` outside the checkout. The older 60002/60001 recovery tools still accept their exact input using `--apk`. Never attempt a downgrade over existing app data without an appropriate backup.
